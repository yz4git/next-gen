# WorldSeed adopters

This file records **verified public downstream usage** of WorldSeed exports or schemas.

WorldSeed does not infer adoption from stars, page views, private conversations, or repository clones. A project is listed only when there is a public artifact that another person can inspect.

## Verified integrations

No third-party integrations have been verified yet.

The repository's own [standalone export consumer](examples/export-consumer/) is a contract test/example and is **not** counted as external adoption.

## Get listed

Open an issue titled `Integration report: <project name>` and include:

- public project/repository/demo URL;
- which WorldSeed version or schema version you use;
- which export files you consume;
- runtime or engine (Three.js, Babylon.js, Godot, Unity, Blender, custom, etc.);
- optional notes about format friction or missing fields.

A maintainer will verify the link and add it here.

## Why this exists

Downstream evidence is more useful than vanity metrics for stabilizing an open interchange format. Integration reports guide schema compatibility decisions and provide reproducible examples for future contributors.
