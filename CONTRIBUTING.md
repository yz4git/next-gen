# Contributing to WorldSeed

Thanks for helping grow WorldSeed.

1. Create a focused branch from `main`.
2. Run `npm install`, then `npm run validate` before opening a pull request.
3. Keep new provider adapters separate from rendering code and include a small fixture-based test.
4. Preserve attribution metadata through normalization and export.
5. Avoid dependencies on proprietary map imagery, scraped map geometry, or undocumented endpoints.

Good first contributions include roof-shape support, better multipolygon assembly, accessibility improvements, additional demo seeds, and output-size profiling.
