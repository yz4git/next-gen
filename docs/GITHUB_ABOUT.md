# GitHub About metadata

The current GitHub connector can edit repository contents but has read-only metadata permission, so the repository Description, Website and Topics must be set in GitHub's **About** panel by a repository administrator.

Recommended values:

**Description**

Turn open geospatial data into playable, exportable 3D worlds with Three.js, GLB, road graphs, colliders, spawn points and JSON Schema.

**Website**

Use the public WorldSeed demo URL when available. Until then, point to the latest release:
https://github.com/yz4git/next-gen/releases/latest

**Topics**

`threejs`, `webgl`, `geospatial`, `openstreetmap`, `overturemaps`, `3d`, `gamedev`, `procedural-generation`, `json-schema`, `gltf`, `city-generator`, `simulation`

These fields materially affect GitHub discovery and should be configured before broad outreach.
